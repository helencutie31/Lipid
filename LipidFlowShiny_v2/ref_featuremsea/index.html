featureMSEA

Feature-based Metabolite Set Enrichment Analysis

FeatureMSEA performs metabolite set enrichment directly from LC-MS metabolic features without requiring confident metabolite identification. By extracting metabolite set-level biological insights from the full untargeted feature space, featureMSEA enables mechanistic interpretation of complex biological phenotypes across diverse applications in disease biology, environmental exposure, drug response, and related research areas.

Help Documents
Overview of featureMSEA

(a) Inputs: untargeted metabolomics data, annotation score table, feature ranking table, and a metabolite set database. (b) Core workflow: feature-level enrichment scoring with iterative leading-edge-guided annotation refinement, permutation-based statistical inference, and optional LLM-assisted interpretation. (c) Key outputs: enriched metabolite sets and a refined annotation score table.

1
Annotation & Filtering

Automatically annotate LC-MS features against KEGG or HMDB databases with customizable MS1 mass tolerance and retention time windows. Redundant annotations are removed to produce a clean feature ranking table.

2
featureMSEA Enrichment

Perform feature-level enrichment scoring across KEGG, Reactome, HMDB, IMetPD, or WikiPathways databases. An iterative leading-edge-guided refinement loop improves annotation quality alongside enrichment scoring.

3
LLM-Assisted Interpretation

Optionally evaluate enriched pathways using large language models. Assess pathway relevance to the sample matrix and research topic, with confidence scores to prioritize biologically meaningful results.

Getting Started: Prepare your feature table in CSV or RDA format, then navigate to the featureMSEA Analysis tab to begin.
